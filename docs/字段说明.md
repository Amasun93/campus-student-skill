# 字段说明（v0.4 字段字典）

> 本文档定义校区学员情况管理 Skill 的完整字段框架，来源于 PRD v1.3 §4。

## 三层架构总览

```
第一层:人工录入层 → 第二层:AI补齐层 → 第三层:AI推算层
  A基础标识            小区房价段          支付力等级
  B家庭背景            周边学校            推荐产品方向
  C在校情况            学校层次+科技特色    续费风险
  D课程成果            周边竞品            转介绍潜力
                       家庭消费力          跟进优先级
```

## 第一层：人工录入层

### A. 基础标识（顾问+老师共录）

| 字段 | 类型 | 必填 | 录入角色 | 说明 |
|---|---|---|---|---|
| 姓名 | String | ✅ | 顾问+老师 | **完整姓名含姓**（大名全名），重名对齐依据 |
| 昵称 | String | | 顾问 | 平时叫的小名 |
| 年级 | String | ✅ | 顾问+老师 | 重名对齐依据 |
| 年龄 | String | | 顾问+老师 | 不确定按年级估，用户可改 |
| 所在校区 | String | ✅ | 顾问+老师 | 多校区支持，首次确认后默认带入 |

> **电话字段不采集**。需要时让校长导家长手机号列表。

### B. 家庭背景与规划（顾问主录）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 家长职业 | String | | 只知领域或大公司名亦可（如"搞IT的""在腾讯"） |
| 单位性质 | String | | 国企/私企/外企/体制内 |
| 家庭结构 | String | | 核心家庭/三代同堂等 |
| 教育氛围 | String | | 家长辅导力度 |
| 居住小区 | String | | AI补齐入口，挺重要 |
| 家长规划目标 | String | | 升学/竞赛/兴趣 |
| 对AI认知度 | String | | 高/中/低 |

### C. 学生在校情况（老师主录）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 学校名称 | String | | AI补齐入口 |
| 成绩水平 | String | | 敏感字段，有大致水平即可（前几名/中等/偏后），不追问具体名次 |
| 性格特点 | String | | 活泼/内向等 |
| 兴趣偏好 | String | | 平时喜欢捣鼓啥 |
| 课堂表现 | String | | 专注/容易走神等 |
| 同伴关系 | String | | 跟同学处得怎么样 |

> **学校层次移至AI补齐层**：老师/顾问不知道就说不知道，AI联网查（含"是否科技特色校"）。

### D. 在读课程与成果（老师主录）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 已报名课程 | String | | 之前报过啥课 |
| 在读课程 | String | | 现在正上着啥课 |
| 学习时长 | String | | 大概几个月 |
| 作品成果 | String | | 做过啥作品/比赛拿过奖没 |
| 续费历史 | String | | 续过费没，几次 |

## 第二层：AI补齐层（校长汇总时联网检索）

| 补齐字段 | 数据来源 | 标注 |
|---|---|---|
| 小区房价段/住户画像 | 联网检索（居住小区） | "AI补齐,请核实" |
| 周边学校学情考情 | 联网检索（学校名称） | 同上 |
| 学校层次+是否科技特色校 | 联网检索（学校名称） | 同上，特别标注科技特色 |
| 周边竞品机构 | 联网检索（小区/学校） | 同上 |
| 家庭消费力评估 | 综合职业+小区推算 | 同上 |

### 联网搜索指引（方向性，非死规则）

| 维度 | 指引内容 |
|---|---|
| 检索方向 | 围绕"居住小区""学校名称"两个锚点，检索房价段/住户画像、周边教育资源、周边竞品机构、学校层次与特色 |
| 检索技巧 | ① 小区名+城市名组合搜索，避免同名小区混淆；② 学校名加"科技特色/重点/普通"关键词；③ 竞品搜索用"小区名+编程/少儿编程/STEAM"组合；④ 交叉验证多个来源取共识值 |
| 灵活执行 | 模型根据自身能力选择检索策略：能联网就用联网，不能就基于知识库推断并标注；检索失败不阻塞，标"待补齐" |
| 结果标注 | 所有AI补齐值统一附"(AI补齐,请核实)" |

### 降级策略

联网失败 → 该字段标"待补齐"，不阻塞流程。

## 第三层：AI推算层（决策标签，系统自动）

| 决策标签 | 推算依据 | 输出形式 |
|---|---|---|
| 支付力等级 | 职业+小区房价段+消费力 | 高/中/低 |
| 适合推荐产品方向 | 校区配置.json推荐规则 + 学生画像 | 课程名 |
| 续费风险 | 学习时长+课堂表现+续费历史+距上次沟通 | 高/中/低 |
| 转介绍潜力 | 家庭结构+家长规划+对AI认知度 | 高/中/低 |
| 本月跟进优先级 | 综合以上四项 | 1-5星（⭐⭐⭐⭐⭐） |

> 决策标签阈值从 `校区配置.json` 读取，每个校区不同，Skill自适配。
