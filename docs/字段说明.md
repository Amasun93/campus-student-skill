# 字段说明（v1.8.0 字段字典）

> 本文档定义校区学员情况管理 Skill 的完整字段框架，与 SKILL.md v1.8.0 同步。v1.8.0 在 v1.7.0 的课程产品库与课程级推荐基础上，新增轻量责任关系系统：主表当前快照 + 责任关系明细表 + 课程段标签。

## 三层架构总览

```
第一层:人工录入层 → 第二层:AI补齐层 → 第三层:AI推算层
  A基础标识            小区房价段          支付力等级
  B1家庭背景           周边学校            推荐产品方向
  B2销售漏斗           学校层次+科技特色    续费风险
  C在校情况            周边竞品            转介绍潜力
  D1课程成果           家庭消费力          跟进优先级
  D2学情履历           推荐话术素材        学情画像（8类标签）
  E学员细节备注
  F三路信源
  G责任关系与筛选标签
```

## 第一层：人工录入层

### A. 基础标识（顾问+老师共录）

| 字段 | 类型 | 必填 | 录入角色 | 说明 |
|---|---|---|---|---|
| 姓名 | String | ✅ | 顾问+老师 | 完整姓名含姓，重名对齐依据 |
| 昵称 | String | | 顾问 | 平时叫的小名 |
| 年级 | String | ✅ | 顾问+老师 | 重名对齐依据；老师侧录入D2后可自动校验更新 |
| 年龄 | String | | 顾问+老师 | 可用于年龄段标签；缺失时可由年级兜底估算 |
| 所在校区 | String | ✅ | 顾问+老师 | 多校区支持，首次确认后默认带入 |

> 电话字段不采集。需要时让校长导家长手机号列表。

### B1. 家庭背景与规划（顾问主录）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 家长职业 | String | | 只知领域或大公司名亦可 |
| 单位性质 | String | | 国企/私企/外企/体制内 |
| 家庭结构 | String | | 核心家庭/三代同堂等 |
| 教育氛围 | String | | 家长辅导力度 |
| 居住小区 | String | | AI补齐入口 |
| 家长规划目标 | String | | 升学/竞赛/兴趣 |
| 家长教育取向 | String | | 鸡血型/理念型/跟风型，顾问第一判断 |
| 家长竞赛认知 | String | | 高/中/低/不了解 |
| 对AI认知度 | String | | 高/中/低 |

### B2. 销售漏斗（顾问主录）

| 字段编号 | 字段名 | 类型 | 必填 | 录入角色 | 说明 |
|---|---|---|---|---|---|
| B2.01 | 客户来源 | 选择题 | ✅ | 顾问 | 大众点评/小红书/转介绍/公众号/地推/其他 |
| B2.02 | 对接次数 | 数字 | ✅ | 顾问 | 跟踪接触轮次 |
| B2.03 | 累计跟进时长 | 文本 | ✅ | 顾问 | 如“3周”“2个月” |
| B2.04 | 当前阶段 | 选择题 | ✅ | 顾问 | 新签挖需/诺访/在读更新 |
| B2.05 | 最初兴趣点 | 文本 | | 顾问 | 切入点留痕 |
| B2.06 | 介绍过的产品 | 文本 | | 顾问 | 家长对哪些方面感兴趣 |
| B2.07 | 堵点 | 主观题 | | 顾问 | 试听后不签约原因 |
| B2.08 | 顾问复盘 | AI生成+顾问确认 | | AI+顾问 | 200字内 |
| B2.09 | 顾问侧续费历史 | String | | 顾问 | 顾问视角的续费情况；D1续费历史为空时可作为补充信源 |

### C. 学生在校情况（老师主录）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 学校名称 | String | | AI补齐入口 |
| 成绩水平 | String | | 敏感字段，有大致水平即可 |
| 性格特点 | String | | 活泼/内向等 |
| 兴趣偏好 | String | | 平时喜欢捣鼓什么 |
| 课堂表现 | String | | 专注/容易走神等 |
| 同伴关系 | String | | 跟同学处得怎么样 |

### D1. 在读课程与成果（老师主录）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 已报名课程 | String | | 之前报过什么课 |
| 在读课程 | String | | 现在正上什么课；可轻量补算课程段标签 |
| 学习时长 | String | | 大概几个月；有入学时间后可自动校验 |
| 作品成果 | String | | 作品/比赛/奖项 |
| 续费历史 | String | | 老师侧续费记录，续费风险优先信源 |

| D2.04 | 在读时长 | 自动计算 | — | 系统 | 小朱每次检查时算 |
| D2.05 | 过往奖项履历 | 文本 | | 老师 | 参加过什么比赛 |
| D2.06 | 特长兴趣 | 文本 | | 老师 | 报过什么课、兴趣方向 |
| D2.07 | 等级考 | 多选 | | 老师 | 默认机器人1-4级/Python1-2级/Scratch1-2级/未考 |
| D2.08 | 白名单比赛 | 文本 | | 老师 | 信奥/科创推荐依据 |

### E. 学员细节备注（顾问+老师均可补充）

| 字段 | 类型 | 必填 | 录入角色 | 说明 |
|---|---|---|---|---|
| 学员细节备注 | String | | 顾问+老师 | 任何不归入A-D结构化字段、但对挖需/推荐有价值的观察和故事片段 |

### F. 三路信源字段说明（家庭背景交叉补充）

| 信源 | 录入角色 | 字段形式 | 说明 |
|---|---|---|---|
| B1 家庭背景（顾问结构化） | 顾问 | 9个结构化字段 | 顾问初次接触家长时采集 |
| B_cross_teacher 家庭背景_老师补充 | 老师 | 自由文本 | 老师日常接触家长时补充 |
| B_cross_principal 家庭背景_校长补充（未来） | 校长 | 自由文本 | 预留接口 |

### G. 责任关系与筛选标签（本版新增）

| 字段 | 类型 | 必填 | 录入/生成角色 | 说明 |
|---|---|---|---|---|
| 当前顾问 | String | | 顾问/校长/系统 | 当前负责该学生的顾问。只有明确说“现在/当前由XX负责”才填写，不猜 |
| 历史顾问 | String | | 顾问/校长/系统 | 曾经负责的顾问。说“以前XX，现在YY负责”时，XX入历史、YY入当前 |
| 顾问关系备注 | String | | 顾问/校长 | 交接背景、口径差异、待确认事项 |
| 交接状态 | String | | 系统 | 只有当前顾问=无交接；只有历史顾问=待确认；历史+当前不同=已交接；多个当前顾问=顾问冲突待确认；全缺失为空 |
| 归属老师标签 | String | | 老师/系统 | 按课程或课程段表达，如“Code2-王老师、PYTHON1-李老师” |
| 课程段标签 | String | | 老师/系统 | 优先 Code2、Code3、PYTHON1、PYTHON2、PYTHON3；归一化 code2/Code 2/code二/C2、py1/Python一等表达 |
| 年龄段标签 | String | | 系统 | ≤8低龄段；9-10小学中段；11-12小学高段；≥13初中段及以上；年龄缺失用年级兜底并标“(按年级估算,待确认)” |

**老师关系强约束**：老师关系必须按课程/课程段表达，如 Code2老师、Code3老师、Python段老师、PYTHON1老师、PYTHON2老师、PYTHON3老师；同一学生可多条老师关系；禁用统称负责人字段或展示口径。

**轻量边界**：v1.8.0 不做完整课程履历、不引入人员ID、不做复杂权限、不做CRM交接流、不改课程推荐核心模型。

## 第二层：AI补齐层（校长汇总时联网检索）

| 补齐字段 | 数据来源 | 标注 |
|---|---|---|
| 小区房价段/住户画像 | 联网检索（居住小区） | “AI补齐,请核实” |
| 周边学校学情考情 | 联网检索（学校名称） | 同上 |

| 推荐话术素材 | 综合学校科技特色+竞赛成绩+学员画像+校区推荐规则 | 同上 |

## 第三层：AI推算层（决策标签，系统自动）

| 决策标签 | 推算依据 | 输出形式 |
|---|---|---|
| 支付力等级 | 职业+小区房价段+消费力 | 高/中/低 |
| 适合推荐产品方向 | 家长教育取向+家长竞赛认知+校区配置推荐规则+学生画像 | 课程名/方向 |
| 续费风险 | 学习时长+课堂表现+续费历史+家长关注度+疲态 | 高/中/低 |
| 转介绍潜力 | 家庭结构+家长规划+对AI认知度 | 高/中/低 |
| 本月跟进优先级 | 综合以上四项 | 1-5星 |
| 学情画像 | D2学情履历+B2销售漏斗+C在校情况 | 8类画像标签 |

## 责任关系明细 Sheet（本版新增）

个人表和汇总表都新增“责任关系明细”sheet。旧版文件缺少该sheet时，合并脚本必须正常运行。

| 列名 | 说明 |
|---|---|
| 姓名 | 学生姓名 |
| 年级 | 学生年级，用于重名对齐 |
| 关系类型 | 顾问/老师 |
| 关系状态 | 当前/历史/待确认/已交接等 |
| 负责人姓名 | 顾问或老师姓名 |
| 课程段 | Code2/Code3/PYTHON1/PYTHON2/PYTHON3/Python段等 |
| 关系备注 | 交接说明、负责课程说明等 |
| 来源角色 | 顾问/老师/校长 |
| 来源文件 | 个人表或汇总表文件名 |
| 更新时间 | 采集或更新日期时间 |

## 学情画像标签体系

| 标签 | 定义（满足全部条件） | 价值 |
|---|---|---|
| 竞赛冲刺型 | 白名单比赛非空 且 等级考含中高级 且 家长关注度=高 | 重点跟进对象 |
| 科创潜力型 | 兴趣偏好含科创/机器人/编程 且 课堂表现积极/主动 且无白名单或等级考≤初级 | 引导竞赛路径 |
| 兴趣探索型 | 兴趣偏好非空 且 在读时长<6个月 且 等级考=未考 | 新生兴趣培养 |
| 续费稳定型 | 在读时长≥12个月 且 家长关注度=高 且 疲态=无 | 续费基本盘 |
| 流失风险型 | 家长关注度低/回复慢/无回复 且 疲态轻度/明显 且 家长新期待为空 | 预警对象 |
| 高净值待挖型 | 老师侧支付力含研学/lab/VEX或支付力=高 且无白名单 且等级考未考/初级 | 高价值客户 |
| 谨慎观望型 | 累计跟进≥2个月或对接次数≥3 且堵点非空 且当前阶段≠在读更新 | 转化策略对象 |
| 基础夯实型 | 在读时长<12个月 且等级考≤初级/未考 且课堂表现稳定踏实 且无白名单 | 基础续推对象 |

  "课程段别名": {
